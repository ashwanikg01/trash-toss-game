# 🗑️ Trash Toss: Desktop Purge
> **PromptWars x OUTLIER'2026 Hackathon Project**

## 📌 Problem Statement
Cleaning up digital workspace clutter—especially bloated ~/Downloads and messy desktop folders—is a chore people constantly put off. Trash Toss transforms file triage into a fast-paced sorting game where gameplay executes real file cleanup actions in the background.

## 🚀 Key Features
- **Arcade Sorting Mechanics**: Rapid 3-bin sorting system via clicks or keys (1=Purge, 2=Documents, 3=Archive).
- **Background POSIX Pipeline**: Real bash (`rm -f`, `mv`) command generation in real-time.
- **Exportable Scripts**: Downloadable `.sh` execution script for local folder cleanup.
- **Ultra Lightweight**: Single-file static HTML5/JS app (<50 KB).
